## 3. 実装した改善（`style.css` 末尾「クーちゃん UI 精査」の塊）

### 3-1. やめた案（理由つき）
- K3 を 1280・1440 にも広げる案：「元に戻す」が1行増え、承認のあとの「ロボットへの送信：していません」がポップアップのスクロールの下に隠れた（1280×720 で確認）。**安全の表示を優先して 1500px 以上だけ**にした。
- 候補が出たときだけ 3D を縮める案：11/5 F7（候補の前後で点を動かさない）に反するのでやめた。
- **K1 の最初の案（JOB を読んだときから 3D の枠の右に 372px を空ける）**：点は隠れなくなったが、1920 で 3D の倍率が 1.754→1.521（**13% 小さい**）になり、e2e の 11/5 F6「3D は小さくならない」が 5件 NG、会話の欄を細くしたため「最新の答えが会話の欄で切れる」も出た。**3D を大きく見せる方を優先して捨てた**。
- 今の K1 は、計画の「候補パネルが会話を覆わない」と字面では合わない。ただし 1100〜1499px では前から同じ置き方が決まっていて、ポップアップの中身は最新の答えと同じ候補（対象・差分・注意・承認の状態）、下の文字の入力欄は見えたまま。**覆うのは候補を確かめている間だけ**。この判断は唐川さんに確認したい（8章）。

## 6. 本番 RC への取り込み（統合の提案）

- **取り込みの状態：未統合**（RC には入っていない）。取り込むかはシクロが差分・テストを見て判断し、唐川さんが承認。
- 取り込み方：`ui/kuchan-ux-1107` の style.css の変更は**末尾の1つの塊だけ**なので、`git cherry-pick <SHA>` か、塊をそのまま RC の style.css の末尾に貼れば入る。戻すときは塊ごと消せばよい。
- ぶつかり：RC で style.css の末尾を同時に直していると、末尾でぶつかる可能性がある（中身は独立なので、両方残せばよい）。
- 動画との関係：K1 は**1920×1080 の撮影の見え方を良くする**（候補の場面で変更の点とオレンジの線が隠れない）。12時の判定で動画用の SHA を決める前に取り込むのがよい。取り込まないなら、撮影では候補のポップアップが点にかぶらない JOB・視点を選ぶ必要がある（DEMO_RJ_XYZ の C00004 はかぶる）。
- 安全の観点：表示の位置・大きさ・余白だけ。承認・出力のボタンの押せる／押せない、文、サーバーの状態は変えていない（e2e の承認・出力・古い候補の確認がそのまま通る）。
