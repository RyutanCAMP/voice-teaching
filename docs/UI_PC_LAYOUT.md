- 入力は1つ（マイク・入力欄・送る）。振り分け（説明・位置の変更・回数の変更）は Step F（`docs/STEP_F_UNIFIED_INPUT.md`）
- 確認表示（全画面：注意・XYZ・図・名前・承認する）は今のまま
- 1100px 未満：3D を上（高さの約45%）、会話を下
- **1280×720 で、3D と会話が同時に見えること・変更の承認に要る情報が隠れないこと**を e2e で確かめる

## 3. 色（ダーク：濃紺・チャコール）
- 地 `#0E1522`、面 `#18212F`／`#202B3B`、文字 `#E8EDF4`、補助 `#97A3B6`
- **オレンジ＝動作の強調・変更後・追加・承認**／**青＝範囲の確認**／**赤＝止める・エラー**／黄＝注意
- **色だけで操作を区別しない**：文言（「範囲を決めるだけです。承認は次の確認表示で行います」など）と置き場所（承認は確認表示の中だけ）でも分かるようにする
- 止まった候補の変更後をオレンジにしない（今の決まり）
- `feat/ui-refresh` のテーマの仕組み（theme.js・図の色の表）を使い、ダークを既定にする
