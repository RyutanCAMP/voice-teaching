## 1. 横・左右の言葉を、視点を確かめてから方向にする
例：
```
人   ：この位置を横に3mmずらして
アプリ：どちらから見て、左右どちらに動かしますか？
        ［ロボットの正面から見て］［ロボットの後ろから見て］［今の 3D の向きで見て］…
人   ：正面から見て右
アプリ：（3D に候補の矢印を出す）この向き（X−）で 3mm ですね？
        ［この向きで］［違う］
```
- 視点と左右の組から軸と符号を決めるのは**プログラム**（Claude の文は使わない。数字・軸もプログラムが入れる）
- 視点と軸の対応は、上下の向き（M2・A案）と同じく、**専門家が設定に登録して確認したものだけ**を使う。未確認なら「左右」を軸に変えず、今どおり「Xプラス・Yマイナスのように言ってください」と案内する
- 3D の矢印は「確認のための表示」。矢印を見せたあとも、軸と符号の確定はボタン、変更の承認は今どおり承認ボタンだけ
- **方向が確定できなければ変更候補は作らない**。会話を分けても、最初の発話の曖昧さを引き継ぐ（CHECKER_028 の P0 の教訓。最後の関門 `utterance.axis_source_gate` を必ず通す）

## 2. 決めること（実装の前に唐川さんと）
1. 視点の種類（ロボットの正面・後ろ・ペンダントを持つ人の位置・3D の今の向き など）と、その確認の方法
2. 「横」「左右」「手前・奥」の言葉の一覧
3. 3D の矢印の見た目（変更量の拡大表示と合わせる）
