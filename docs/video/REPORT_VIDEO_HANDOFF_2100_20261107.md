## 1. 最初の自己申告：この環境で動画編集・MP4 書き出しはできるか（16:40 実際に試した）

| できること（試して確認） | 結果 |
|---|---|
| コマンドの `ffmpeg 6.1`（libx264・AAC・libass 字幕・drawtext） | **ある** |
| 1920×1080・30fps の H.264＋AAC の MP4 を作る | **できた**（テスト映像 4秒） |
| 日本語の字幕（SRT）を焼き込む（IPAゴシック・WenQuanYi） | **できた**（1フレームを書き出して目で確認） |
| 黒地に白文字のエンドロール・タイトル・出典の文字の動画を作る | できる（ffmpeg の文字の描画） |
| 素材の切り出し・並べ替え・つなぎ・音量の調整・3分の尺の確認 | できる（ffmpeg。素材があれば） |

| できないこと・前提が足りないこと | 理由 |
|---|---|
| **実機の撮影素材（LUMIX）・本人の声・BGM・AI 生成の映像** | このクラウドの環境に無い。GitHub にも無い（大きな動画・個人の映像は GitHub に置かない方針）。**唐川さんの PC にある** |
| **Clipchamp の「Voice Teaching」プロジェクトの続き** | Windows のアプリ。この環境から GUI のアプリは操作できない |
| アプリの画面の収録（本物の Claude） | API のキーがこの環境に無い。モックの画面は「MOCK」の印が出るので本番の動画には使えない |
| 出来上がった MP4 を唐川さんに渡す | GitHub に大きな動画を置かない方針。小さな部品（エンドロールなど数 MB）なら、置くかどうかを唐川さんに確認してから |
| YouTube の限定公開・提出 | 本人の操作。代理でしない |

**結論：この環境では、素材が無いので「本編の編集」はできない。** できるのは、①編集担当（唐川さんの PC の Clipchamp、またはチャッピーの分身）にそのまま渡せる**台本・タイムコード・字幕（SRT）・編集の指示**、②素材に依らない**部品の動画の作り方**（エンドロール・タイトル・出典の文字）を ffmpeg の道具として用意すること。**「編集完了」とは報告しない。**
