## 1. 画面の収録（約 20〜30分）

**準備**
1. アプリを起動する（シクロの 17時の引き継ぎ `release/v1.0-rc:handoff/HANDOFF_1700_20261107.md` 2章）。PowerShell：
   - `cd C:\Users\User\vt-rc`（本番候補の作業フォルダ）
   - `$env:PYTHONUTF8="1"; $env:PYTHONIOENCODING="utf-8"`
   - `<venv の python.exe> -m voice_teaching.web --port 8901 --channel filming --env-file <.env の場所>`
   - 起動の窓に「解釈：本物の Claude」と出ることを確かめる（最初の準備に 30〜40秒）
2. **Google Chrome** で `http://127.0.0.1:8901/` を開く（Chrome 以外だと「アプリの中で開いた画面では…」の帯が出て映る）。全画面（F11）・通知を切る・画面は 1920×1080
3. 録画：Windows の **Xbox Game Bar（Win＋G）** か Clipchamp の画面の録画。音（マイク）も一緒に録る
4. **マイクを1回試す**（最終版の実マイクはまだ誰も確かめていない）。話して文字になれば OK。だめなら文字で入れて撮り、動画では「声で」と言わない

**撮る順（1本で通して撮る。失敗したら最初から撮り直してよい）**
| # | 操作 | 画面に出るもの（期待） |
|---|---|---|
| 1 | アプリを開いたところから録画開始 | 「話して、動きを確かめる。」の最初の画面 |
| 2 | `DEMO_RJ_XYZ.JBI`（`samples\dummy\`）をドロップ | 3D の点と軌跡 |

- 8 のあと、今の版は 1920 で候補の窓が C00003〜C00005 と線を隠す（UI-1700-1、未修正）。**7 の候補の窓の場面を長めに撮っておけば**、編集で困らない
- 8 の結果の表示は「✓」が2つ出る（UI-1700-2、未修正）。動画ではそこを長く映さない・拡大しない
- 保存の窓（OS の画面）が出るかどうかは、まだ人の手で確かめていない。出なければ「ダウンロードとして保存」を押す。動画には、出たほうを使う
