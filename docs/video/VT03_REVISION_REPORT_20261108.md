### E3とE5：指定文の実長に合わせた調整

指定全文はNaoki・低・0.95で17.28秒だった。「約12秒」に合わせて早口にせず、全文を残した。物理映像52.5秒＋起動5秒＝実演開始0:57.5。次の旧時刻を短縮し、**実機比較以降の開始時刻を仕上げ02と同じに保った**。

| 仕上げ02から除いた区間 | 短縮 | 内容 |
|---|---:|---|
| 0:40–0:43 | 3秒 | 5mm発話前の待ち |
| 1:00.5–1:02 | 1.5秒 | 数値説明が終わった後の静止 |
| 1:15–1:20 | 5秒 | 拒否の説明後の静止。拒否の寄りは約5秒を確保 |
| 1:20–1:24 | 4秒 | 回数の発話前の待ち |
| 1:36.8–1:39.8 | 3秒 | 範囲説明が終わった後の待ち |
| 1:55–1:56 | 1秒 | 3D回転の一部 |
| 合計 | **17.5秒** | 本人の発話を含まない |

省いた説明音声は「合成ジョブを読み込み、変更する位置を選びます」「次は、同じ動きを繰り返す回数の変更です」。画面の選択と見出しで内容は示し、本人の発話に重ねて再生しない。

指定全文と画面の短い字幕は文意を合わせている。音声用の「人」は「ひと」で入力。別添SRTは新時刻の29件。
