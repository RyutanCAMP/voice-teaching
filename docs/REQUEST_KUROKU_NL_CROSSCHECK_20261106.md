## 依頼 2：「だめ」「ノー」「大丈夫？」の分け方（D3 の細かい決まりを決めるため）

P0 の確かめの 47件の FAIL（と F-3 の 69 の言い方）を、次の3つの組に分けてください。

| 組 | 例 | 確定した最低限 |
|---|---|---|
| ① 否定 | だめ・ノー・違う・やめて・出さないで・きゃんせる | 承認しない。**承認済みなら承認を取り消す** |
| ② 質問 | 大丈夫？・合ってる？・本当に？ | **質問として扱う**。承認・変更の意思にしない |
| ③ どちらとも言えない | うーん・ちょっと待って | （今の保留のまま） |

組ごとに、次の6つの場面で今どうなるかを表にしてください。

- 候補なし
- 未承認の候補あり
- 承認済み

あわせて、次の2つについて、**クロークの意見**を書いてください（決めるのは唐川さん）。

- 承認済みのときの②：保留にするか、承認を残すか
