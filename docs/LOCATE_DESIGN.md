## 1. 何をするか（1行）
利用者が位置番号ではなく「置くところ」と言ったとき、Claude がジョブの命令の並びから位置の候補を**根拠つきで**示し、**人がボタンで選ぶ**。選んだあとの変更（軸・向き・量）は、今までどおりプログラムが発話から読み、照らし合わせ・確認表示・ボタンの承認を通る。

## 2. 変えないこと（安全の線引き）
- Claude はジョブの文字列を書かない。位置の候補は「選ぶ」だけで、ジョブは変わらない
- 位置を選ぶことと、変更を承認することは別のボタン。どちらも声では行わない
- 数字（量・座標）は Claude に決めさせない。根拠の文もプログラムが作る（Claude は行番号を返すだけ）
- 推定した名前（「置くところ＝C00005」）は、そのセッションの中だけで「推定（未確定）」として扱う。保存しない。確定した名前は FRAME の label・aliases（専門家の review 済み）だけ
- 「安全です」「当たりません」などの断定は使わない。DOUT・TIMER の意味（つかむ・離す）も断定しない（「信号を切る」「待つ」など、命令の事実だけを書く）

## 3. 流れ
```
「置くところを3mm下げて」
  ① プログラム：位置番号が無い・「この位置」も無い → 位置の言葉（置くところ／置き場所／取るところ…）を取り出す
     - 知らない言葉・打ち消しの検査（B1・B6）は今までどおり先に行う（位置の言葉は、決めた一覧にあるものだけを使ってよい言葉にする）
  ② FRAME があり、aliases に一致 → その位置（確定した名前）。Claude は呼ばない
  ③ FRAME が無い・一致しない → Claude に「位置の候補」を頼む（下の4章）
  ④ 画面：「置くところ」の候補（最大3つ）を、根拠の行と一緒に出す。［C00005 を選ぶ］［ほかの位置を選ぶ］
     - 3D の図で候補の点を光らせる
  ⑤ 人が選ぶ → 選んだ位置で、同じ発話の「3mm下げて」をプログラムが読み直す（今の流れ。D1・D2・B1・B6 もそのまま）
  ⑥ 変更の候補 → 確認表示 → 承認ボタン（今のまま）
```
⑤で発話の残りが読めなければ（量が無い等）、今どおり聞き返す。

## 4. Claude に頼む形
- 道具 `propose_target`（strict、additionalProperties:false）
  - `candidates`：最大3件。各件は `position`（位置番号の一覧からの enum）、`evidence_lines`（ジョブの命令の行番号の配列、1〜5件）、`rank`（1〜3）
  - 自由文は受け取らない（理由の文章は使わない）。`ask_user`（固定文に置き換える）は今どおり
- 送るもの（**案A**）：発話、位置番号の一覧、**命令の行（//INST の部分）と行番号**、ジョブのコメント行
  - 送らないもの：//POS の座標の値、//NAME 以外の見出し、APIキー
  - 送ってよいジョブ：合成ジョブ（`sim._is_synthetic` が真のもの）だけ。それ以外は Claude を呼ばず「位置を選んでください」
- **案B**（FRAME ができたあと）：FRAME の label・aliases の一覧だけを送り、Claude はその中から選ぶ。ジョブの中身は送らない

## 5. プログラムの照合（Claude の答えをそのまま使わない）
- `position` が一覧にある。`evidence_lines` がすべて命令の行の範囲にあり、少なくとも1行がその位置を参照する命令（MOVL C00005 …）か、その直前・直後の行
- 根拠の表示はプログラムが行の中身から作る（例：「MOVL C00005 V=50.0 PL=0 の行／次の TIMER T=3.00（待つ）の行／次の DOUT OT#(1) OFF（信号を切る）の行」。行番号の数え方は実装のときに jbi の命令の番号に合わせて決める）
- 照合に通らない候補は捨てる。全部捨てたら「位置を選んでください」（推測で補わない）
- 1件だけでも自動では選ばない（必ず人がボタンで選ぶ）

## 6. 画面
- 候補のカード：「『置くところ』の候補（Claude の推定・未確定）」＋候補の位置番号＋根拠の行（プログラムが作る）＋［この位置を選ぶ］
- 選んだあとも、位置の欄に「推定で選んだ位置」と小さく残す。確認表示にも出す
- モックのとき：位置の推定はしない（「モックでは位置の推定をしません。位置を選んでください」）。モックで推定したように見せない

## 7. 受入テスト（先に書く）
1. 「置くところを3mm下げて」（本物の Claude の代わりに、決まった答えを返す偽物）→ 候補 C00005・根拠は MOVL C00005 と、その次の TIMER・DOUT の行 → まだ変更の候補は無い → ［選ぶ］→ Z −3 の候補 → 承認ボタンまで
2. 偽物が一覧に無い位置・命令の範囲外の行・その位置と関係の無い行だけを返す → 候補として出さない
3. 偽物が自由文・余計な項目・4件以上を返す → 使わない
4. 合成でないジョブでは Claude を呼ばない（呼ばれた回数 0）。送る内容に座標の値・//POS が無い
5. 「置くところじゃなくて…」「置くところを下げないで」→ B6 で止まり、Claude を呼ばない
6. 候補を選んでも、ジョブ・承認・出力は変わらない。声で「選んで」「それで」と言っても選ばれない
7. 根拠の文に断定の言葉が無い（DOUT・TIMER を「つかむ」「離す」と書かない）
8. モックでは推定しない・推定したように見せない
9. FRAME の aliases に一致すれば Claude を呼ばない（FRAME の実装後）
