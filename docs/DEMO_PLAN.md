## 1. 見せる筋
**「ずれていた → 声で直す（範囲を超える量は止まる） → 人がボタンで承認 → 新しいジョブ → 人がスタート → 印に合った」**

- 一言：「専門家が決めた枠の中で、現場の人がロボットに声で直しを頼める。」
- 立ち位置：専門家をいらなくするのではなく、**専門家の判断を現場に届ける**。
- 主役は位置の左右の微調整（困りごと①）。速度（困りごと②）は動画では触れず README に書く（位置で撮れないときの代わりの手は7章）。

## 6. ルール上必要な表示と、言葉の決まり

**必ず入れる表示**
| 内容 | 入れる場所 | 根拠 |
|---|---|---|
| 期間中に作った部分だけを紹介する（アプリの画面と、その出力が実機で動く所だけを見せる。以前の試作は映さない） | 全体 | 決定事項1章（判別できないと失格） |
| 既存部分の明示「ロボット・ペンダント・転送機能は安川の既存製品。期間中に作ったのはこのアプリ」 | 場面11（場面8・9でも「安川の既存製品」と補足） | 決定事項1章、仕様9章 |
| 音声の送り先「文字起こしは（方式名・送り先）、解釈はClaude」 | 場面4 | 仕様8章 |
| 「実際の運用では低速で動作確認する」 | 場面9 | 決定事項4章 |
| 「デモのため、わざとずらしています」 | 場面1 | 仕様9章 |
| 図は変更を見比べるためのもので、干渉・到達性を保証しない（画面の固定の注記） | 場面3・6 | 仕様4章 |
| 固定データを使う場面では「例のデータ」 | 場面10 | 仕様5-3b |
| 家のPCと会社の実機をつないだ場合、「その場で」と言わない | 全体 | 仕様9章 |

**言葉の決まり**
- 「安全です」「当たります」「干渉します」など、安全や距離を**断定する言葉はナレーション・字幕に使わない**（CLAUDE.md）。言うのは「専門家が決めた範囲に対してどうか」だけ。
- 「専門家がいらなくなる」とは言わない。「**専門家の判断を現場に届ける**」。
- 「誰でも直せる」ではなく「専門家を呼ばずに、現場の（教育を受けた）担当者が直せる」（言い換えは本人が確認中）。
- 実機で確認していないことを「確認済み」と言わない。1mm は使わない。
- 字幕の文ができたら、断定の言葉が入っていないかを文字検索で確かめる（11/6の「必要な字幕の一覧」の作業に含める）。

## 7. 撮影前の確認手順（参照）
仕様 v2.1 6章「撮影前の確認手順」（本人に必須項目として提案中）：
1. 変更後の初回は、カメラの外で低速・ステップで確認する
2. 撮影中は動作範囲に人がいない（協働ロボットでも）。非常停止の位置を確認
3. 動かす向き（右）の空きと、周辺の物の配置
4. 背景に社内の設備・他社の案件・人が映らない
5. 指し棒を付ける場合は軽い部品にする。ツールの重さ・寸法の設定は本人が判断して変える

あわせて `docs/REAL_MACHINE_CHECK.md` の4章（生成したジョブの差分、座標系、速度、動作範囲の確かめ方）を使う。枠の範囲（右へ＋12mm）と実物の箱の間には、腕やツールの根元を含めて十分な余裕を取る（量は本人が決める）。

## 8. 遅れた場合の代わりの手（仕様12・13章）
| 起きたこと | 代わりの手 | 動画で変える所 |
|---|---|---|
| 3Dが間に合わない | **2Dの静止図で撮る**（上から見た図、枠の線を光らせる） | 場面3・5・6 |
| 位置の変更が実機確認で通らない／位置がロボット座標で保存されていない | **速度で撮る**：場面1「遅くてタクトに間に合わない」、場面4「もう少し速くして」→「何%上げますか？」→「30%」→ 助言で止まる →「20%」、場面9は比較映像＋サイクルタイムの字幕（上限の値は本人が11/4夜に確認） | 場面1・4・5・6・9 |

| Claudeの応答が遅い | 早送り＋字幕「Claudeが考えています」 | 場面2・4・5 |

| Ethernet転送が組み込めない・実機で未確認 | USBで読み込む | 場面8 |
| 変更記録・申し送りが間に合わない | 場面10を削り、秒を場面9・11へ | 場面10 |
