# MOVJ の目標位置の変更：設計（安全修正のあとに実装）

書いた人：シクロ（会社の PC）。2026-11-03。
きっかけ：唐川さんの指示（MOVJ の目標位置も MOVL と同じように XYZ を変えられるようにする。直線移動とははっきり区別する）。
これまでの決まり（CURRENT_DECISIONS「移動命令：MOVL だけ」、CLAUDE.md「MOVL 以外は止める」）を、**MOVJ の目標位置に限って**変える仕様の変更。
状態：**設計だけ**。M1〜M3 の修正と `////FRAME ROBOT` の対応を合わせたあとに実装する。今回の範囲は「目標位置の変更と、変更前後の比較」まで。関節ごとの動きのシミュレーションは、ロボットのモデルと運動学を作ったあとにする。

## 1. 変えること・変えないこと
| 変えること | 変えないこと |
|---|---|
| `MOVJ C… VJ=数値`（PL なし、またはちょうど PL=0）の行き先の位置の X・Y・Z を、候補にできる | 命令は MOVJ のまま。MOVL に変えない。VJ= も変えない |
| 確認表示・3D に、変更前後の目標位置と数値を出す | 姿勢（Rx・Ry・Rz）・RCONF・TOOL・座標系の行は変えない |
| MOVJ の区間に「関節移動のため、実際の通過経路は再現していません」と出す | MOVJ の区間を直線として描かない・再生しない（S-MOVJ の表示のまま） |
| 候補の注意に「到達できるか・周りの物との位置関係は、このアプリでは確かめていません（逆運動学・経路の検査はありません）」を必ず付ける | 1回の上限 20mm・累積 20mm・承認はボタンだけ・承認後の変更で承認を消す・合成ジョブ以外は出力しない・転送・起動しない |

「安全です」「当たります」「干渉します」は使わない（注意の文も同じ）。

## 2. MOVJ の目標位置を変えてよい条件（すべて満たすとき）
今の MOVL の条件（ロボット座標・値が6個・止める命令が無い・制御の流れが無い・共用していない、など）は、そのまま全部かける。そのうえで次の条件を足す。
1. その位置を使う命令がちょうど1つで、それが `MOVJ 位置 VJ=数値`（ちょうど ` PL=0` は可。PL>0・CR・ほかの付加は止める）
2. 位置の形式：`///POSTYPE ROBOT`・`///RECTAN`、`///USER` なし（または `////FRAME ROBOT` の相対ジョブ。FRAME 対応の5条件）
3. RCONF：位置の前に `///RCONF` があり、数字の並び（8個、または24個）で読める。**無い・読めないときは止める**（関節移動では形態で関節の解が変わるため）
4. TOOL：位置のツール番号が読める。前後の移動命令の位置とツール番号が違うときは止める（ツールの切り替えの意味が分からないため）
5. 入る区間（前の移動命令から、この MOVJ）：関節移動で、通り道は描かない。前の移動命令が無くてもよい（最初の MOVJ：始まりはロボットのその時の位置。ジョブの中では決まらない、と注意に出す）
6. 出る区間（この位置から、次の移動命令）：
   - 次が無い（END）→ 可
   - 次が MOVJ → 可（関節移動。描かない）
   - 次が MOVL → その MOVL は、新しい目標位置から始まる直線になる。今の MOVL の「始まり」の条件（`MOVL 位置 V=数値`、PL=0 は可）を満たせば可。変更前後の直線を図に出す
   - 次が MOVC・MOVS・そのほか → 止める

## 4. 受入テスト（先に書く。合成ジョブ `DEMO_RJ_XYZ.JBI` と、テストの中で作るジョブ）
1. 最初の MOVJ の位置（C00000）で「Zマイナス3ミリ」→ 候補。命令は MOVJ のまま。出力（合成ジョブ）で変わるのは、その位置の Z の1つの値だけ（ヘッダー・RCONF・FRAME・姿勢はバイト列のまま）
2. 最後の MOVJ の位置（C00006）で「Xプラス5ミリ」→ 候補。注意の文がすべて出る
3. MOVJ の PL=1・CR・VJ が数値でない・RCONF なし・RCONF が読めない・TOOL が前後で違う・///USER・POSTYPE PULSE → 止める（理由の文）
4. MOVJ の次が MOVC → 止める。次が MOVL → 候補になり、図にその直線の変更前後が出る
5. 上限：21mm で止まる。累積 20mm を超えると止まる。0mm で止まる
6. 承認・出力・承認後の変更・上下の照合（M2）は MOVL と同じに動く。実機のジョブは出力しない
7. MOVL の点（MOVJ の隣の C00001・C00005）は、今どおり止まる（9章の決定まで）
8. 図のデータ：MOVJ の区間は kind=movj のまま。再生の印は MOVJ の区間で直線の上を動かない（e2e）
9. 画面・注意の文に禁止語が無い
