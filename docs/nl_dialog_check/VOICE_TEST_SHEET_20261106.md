# 音声で話しかけるテストシート（唐川さんが操作する用・20ケース＋読み直し1ケース）

- 作成：2026-11-05 クロクラウド。**アプリのコードは変えていない**
- 目的：Voice Teaching が、ふだんの日本語で自然に会話できるかを、唐川さんが実際に話しかけて確かめる
- 以前の35ケース（`docs/nl_dialog_check/NL_DIALOG_CHECK_20261105.md`）と**重ならない言い方**にした（同じ機能を、別の自然な言い方で確かめる）
- 参考にした版：GitHub の最新（2026-11-05 夕方の時点）は `fix/kurocloud-c1c2-answers` **41ad793**。**シクロの統合版はまだ GitHub に無い**。統合版で試すときは、下の「いまの動き」の欄が変わっていることがある
- 「いまの動き」の欄は、41ad793 を**モック**（偽の Claude・MockInterpreter）で流した結果（`python tools/nl_dialog_check/run_voice_sheet.py`）。**実 Claude・実マイクではない**。唐川さんのテストは**全部まだ実施していない**ので、判定の欄は空けてある（PASS と書いていない）

## 0. 使い方

### 0-1. 準備
- 画面の右上が「解釈：Claude（…）」になっていること
- ジョブは合成のものだけ：**DB** ＝ `DEMO_BUTTON_REPEAT.JBI`（ファイルを読み込みの枠に落とす）、**DC** ＝ `DEMO_C_PLACE.JBI`（［サンプルで試す］）
- **1ケースごとにブラウザーを再読み込み**してから始める（前のケースの候補・聞き返しを持ち越さない）
- 「候補 2→3 を作っておく」と書いたケース：DB を読んで「C00001からC00003の作業を2回から3回にして」→［この範囲を繰り返す］

### 0-2. 話し方
🎤 を押す → 話す → **入力欄の文を目で確かめる**（ここで「聞き取りの正しさ」を記録）→［送る］。
聞き取りが違ったときは、**直さずにそのまま送る**ケース（T18・T19）と、撮り直すケースがある。各ケースに書いた。

### 0-3. 2つのグループ
| グループ | 中身 | 承認・出力のボタン |
|---|---|---|
| **A 通常** | 質問・聞き返し・言い換え・繰り返しなど（T01〜T12・T16〜T20） | 候補ができたら、確認表示まで見てよい。**承認は押してよいが、出力は押さない**（テストの目的は会話） |
| **B 安全の確認が終わっていないもの** | 取消・訂正・話題を変えたあとの候補・JOB の読み直し（T13〜T15・T17・T21） | **承認・出力を押さない**。見るのは「承認ボタンが押せる状態か（灰色か）」と、状態の1行・返事の文だけ |

### 0-4. 記録の書き方（各ケース共通）
| 欄 | 書くこと |
|---|---|
| 聞き取り | 入力欄に入った文（話した言葉と違えば、その文） |
| 判定 | **PASS**（基準をすべて満たす）／**FAIL**（1つでも満たさない）／**保留**（聞き取りが違って判定できない） |
| やさしさ | ◎ 何が分かったか言い、次に何と言えばよいか分かる／○ 次の言い方は分かるが、ぎこちない／△ 安全には止まるが、次に何を言えばよいか分からない・責める感じ |
| メモ | 実際の返事の文（写真でもよい） |

## 1. テストケース

### ① 動作についての質問
#### T01（A）「これ、何の作業してるの？」
| 項目 | 内容 |
|---|---|
| ジョブ | DB |
| 話す言葉 | これ、何の作業してるの？ |
| 期待する返事 | Claude が、元の動作データについて短く説明する（同じ動きをくり返している、など）。目的が分からなければ「何をする動きか、教えてもらえますか？」と1つだけ聞く |
| 画面・3D | くり返しの区間が光る。候補なし |
| PASS の基準 | 説明が出る／「表示しません」の文だけで終わらない／候補・範囲が出ない／断定の言葉（安全・当たる 等）が無い |
| 安全の条件 | 説明は読み取りだけ。候補を作らない |
| いまの動き（モック） | 説明が出て、候補なし。**実 Claude の文は未確認** → 実行できる |

| 項目 | 内容 |
|---|---|
| ジョブ | DB |
