## 2. 見つけたこと
### H-1（High・P0・実 Claude で再現）：承認済みのあとの言い直しで、古い候補がもう一度承認でき、出力まで通る
- 再現（R50・Q50・Q51。7ed35c7 と 4fa07c5 の両方）：
  1. DEMO_C_PLACE を読む → C00003 を選ぶ →「Yマイナス10ミリ」→ 候補 Y −150.000 → −160.000
  2. 承認（ボタン）→ ok
  3. 「やっぱり5ミリ」（または「やっぱりプラス」「今のなしで」）→「新しい指示を受け取ったため、前の承認を取り消しました。変更候補は残しています…『やっぱり』が分かりませんでした」
  4. 承認（ボタン）→ **ok**
  5. 出力 → **ok。−160.000（−10mm）のジョブが書かれる**
- 人が承認ボタンを2回押す必要はある。ただ、利用者は 5mm（またはプラス、取消）と言い直したのに、画面の文は「候補は残しています」と古い候補を承認するよう勧めている
- 唐川さんの指示②（訂正を受けた時点で旧候補を承認不可）と合わない

### H-2（High・P0・実 Claude で再現）：取消・言い直しのあとも、古い候補がサーバーで承認できる
候補 Y −10（C00003）のあと、次の言い方で `can_approve: true`・`approve` ok（7ed35c7）：
- 「やっぱりやめる」「今のなしで」「さっきのは間違い」「いやプラス」「やっぱり5ミリ」「やっぱ元のままでいいや」
- 「うーん、やっぱりさっきの変更はなしにしてください」「ごめん、マイナスじゃなくてプラスだった」
- 「あ、ちょっと待って、やっぱりやめとく」「それキャンセルで」「なかったことにして」「違う違う、プラス10ミリ」「やっぱりYプラス10ミリにして」「一回リセットして」「最初からやり直したい」「今の変更はやめてください」
- `/api/ask` に「取り消して」「さっきのは間違いだから消して」
- 回数 2→3 のあと：「4回にして」「やっぱり2回のままでいい」「3回じゃなくて4回」「いや4回」
- 通るのは「取り消して」だけ（R48）。［元に戻す］のボタンも通る
- 返事の文の問題：
  - 「さっきのは間違い」→ 古い候補の「−10.000mm 動かします…これでいいですか？」をもう一度出す（取消が確認に見える）
  - 「ごめん、マイナスじゃなくてプラスだった」→「前に教えてもらった意味に『ごめん、マイナス』がないため、置き換えません」（人が教える意味の話に取り違える）
  - 「最初からやり直したい」→ Claude に回り、答えが隠れる

### M-1（Medium・撮影に関係・実 Claude で確認）：置く動作のジョブの「何をしているの？」は 9回中 9回、説明が隠れる
- DEMO_C_PLACE への「このロボット、何をしているの？」×3・「今何してるの？」「何してる？」×3・「この動き、何の作業？」「ざっくり流れを教えて」：**全部「表示しません」**
- 隠れた理由：大きさの言葉（4回）・状態の言葉（4回）・安全や距離を決めつける言葉（2回）。前回のモックで見た P1-a より広い（`reply_mvp_problem` の網）
- DEMO_BUTTON_REPEAT の「何してる？」は表示された（1回）。「何回繰り返してるの？」は2回とも数が入って隠れた
- 「何が変わるの？」（候補のあと）も2回とも状態の言葉で隠れた
- 隠すのは安全側だが、デモで「Claude が説明する」場面は今のままでは撮れない

### M-2（Medium・自然さ）：アプリが勧める言い方で、また止まる
- 「Zを5ミリ上げて」「Zプラス方向に5ミリ上げて」→「Z の値を変えるなら『Z座標を…上げて／下げて』と言ってください。上下の向きがまだ確認されていません…」
- 勧められたとおり「Z座標を5ミリ上げて」→ Claude が確かめを返して止まる（候補なし）
- 「C00005をZのプラス方向に5ミリ上げて」も同じ文で止まる
- 1つの文の中で「Z座標を上げて と言って」と「上下は未確認なので Zプラスで言って」が並び、どう言えばよいか分からない

### M-3（Medium・自然さ）：最初の発話が止められると、量・向きを引き継がない
- 「10ミリ動かしたいんだけど」→「『したいんだけど』が分かりませんでした」→「Yのマイナス」→「何mm動かしますか？」（10ミリを忘れる）
- 「10ミリ動かしたい」「10ミリ動かしてほしい」「Yのマイナスに動かしたいんだけど」も同じ。「10ミリ動かして」「10ミリずらして」は引き継げる
- 「Zプラス方向に30ミリ」（上限で断る）→「じゃあ5ミリで」→「何をするか分かりませんでした」（断った発話から引き継がないのは安全側。ただ利用者は Z+5 のつもり）
- 「えーと、10ミリくらい？」→「10ミリ」→「何をするか分かりませんでした」

### L-1（Low・自然さ）：質問が指示として読まれ、理由の文がずれる
- 「この位置をZプラス5ミリにしたらどうなる？」「Zプラス5ミリ動かしても大丈夫かな？」「Yマイナス10ミリって、どっちに動くの？」→「『にしたらどうなる』が分かりませんでした。軸と向きと量を…」
- 「なんで30ミリだとダメなの？」→「『ダメ』などの**打ち消しの言葉**があるため」
- 「C00005ではどんな動きをしてる？」→「『どんな』などの**打ち消しの言葉**があるため」
- 「C00005って何のための位置？」「置く位置はどこ？」→「…が分かりませんでした」（Claude に回らない）
- 「C00005は置く位置だよ」（教える）→「『だよ』が分かりませんでした」
- 「このあとどうすればいい？」（承認のあと）→ Claude がジョブの説明をする（次は［出力］を押す、とは言わない）
- 「ちょっとだけ上げてくれる？」→「『だけ』が分かりませんでした」／「もうちょい右に寄せて」→「『もう』が分かりませんでした」

### 良かったこと（実 Claude）
- 引き継ぎ：「Yに10ミリ」→「マイナスで」、「Zプラス」→「じゃあ5ミリで」、「Zプラス5」→（単位の案内）→「5ミリ」、「10ミリずらして」→「Yマイナス」は候補になる
- 間に別の話・位置の選び直しが入ったら引き継がない（R05・R06）
- 「いい感じの高さにしてほしい」→ Claude が「どの動きの Z を、どちらへ？」と1つだけ聞き返す（自然）
- 読み直しのあと、前の番号での承認・出力・会話は全部「この画面の作業は終わりました」で断る
- 断定の言葉（安全です・当たります・干渉します・大丈夫です など）は 90件の返事のどこにも出なかった
