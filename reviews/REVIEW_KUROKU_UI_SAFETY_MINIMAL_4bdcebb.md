## 4. 承認状態のアイコン（これからシクロが実装する）：入れるときの条件（未確認）
サーバーの状態（`state`）で区別する。今の値はクロークが確かめた。

| 状態 | サーバーの値 | アイコン |
|---|---|---|
| JOB 未読込・候補なし | `candidate` なし | 承認の印を出さない、または「承認なし」（緑にしない） |
| 未承認 | `candidate` あり・`approval` なし | 未承認の形（緑にしない） |
| **承認済み（出力できる）** | `approval` あり・**`hold` false**・`can_export` true | ここだけ緑の ✓ |
| **保留** | `approval` あり・**`hold` true**・`can_export` false | **緑にしない**（例：一時停止の形・「保留：承認・出力はできません」）。`approval` があるだけで緑にすると UI-1 と同じになる |
| 承認を取り消した（F-1・F-2・取消・言い直し） | `approval` なし（`voided` のことがある） | 未承認・無効の形 |
| 出力済み | `exported` あり | 出力済みの形。そのあと言い直したら消える（U22 と同じ） |

- 色だけで分けない（形・ツールチップ・アクセシブル名）。文はサーバーの `status_line` に合わせる。
- ポップアップの中の緑の ✓（`#approval-status`）と、3つの状態の「人が承認しました」も、`hold` のときは緑のままにしない（UI-1）。
- 実装されたら、`ui_probe.py` の U10〜U23 に、アイコンの確かめを足して流し直す（5分ほど。API 0回）。
