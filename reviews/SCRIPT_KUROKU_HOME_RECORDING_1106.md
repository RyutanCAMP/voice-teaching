## 3. 失敗しやすい言い方と、よける方法
| 言い方・操作 | どうなる | よけ方 |
|---|---|---|
| C00005 を選ぶ | 次が MOVJ のため承認できない（参考の表示だけ） | **C00004** を選ぶ |
| 「上に5ミリ」「5ミリ上げて」 | 「上は Zプラス で合っていますか？」の聞き返し。「はい」でも候補にならない | 「**Zプラス**」と言う |
| 「4回にして」 | 断る（2回から3回だけ） | 「2回から3回」と言う |
| 範囲を声で「はい」 | 決まらない（ボタンで決める） | ボタンを押す |
| 候補があるまま回数を言う | 「承認待ちの変更候補があります…」で回数に進まない | JOB を読み込み直す |
| **出力のあとで続けて別の量を言う** | 承認は取り消されるが、**新しい候補にならず古い候補が残る** | シーンの間は「取り消して」か JOB の読み込み直し |
| 実機の JOB で「2回から3回にして」 | 「架空のサンプルではないため…送りません」 | 合成ジョブ DEMO_BUTTON_REPEAT を使う |

## 4. 失敗したときのやり直し（確かめ済み）
| 場面 | 手順 |
|---|---|
| 違う候補・聞き返しが出た | 🎤「**取り消して**」→「前の承認と変更候補を取り消しました。元のJOBは変更されていません」→ もう一度、全部言い直す（2/2） |
| 承認のあと迷った | 🎤「ちょっと待って」→ 保留 → 「このままでいい」→ **承認ボタンで承認し直す** |
| 範囲の確認が出たまま | ［違う］を押して言い直す |
| どうにもならない | **JOB を読み込み直す**（候補・承認は残らない） |

## 5. 状態が残らないかの確認
| 確かめたこと | 結果 |
|---|---|
| JOB の読み込み直し・別の JOB を読む | **成功**：候補・承認・範囲の確認は残らない（2/2） |
| 「取り消して」 | **成功**：承認も候補も消える（2/2） |
| 出力のあとの新しい指示 | **注意**：承認は取り消す（承認・出力はできない状態になる）が、古い候補が残り新しい候補を作らない（2/2）。安全側だが紛らわしいので撮影では避ける |
| 断られた候補（参考の表示）のあとに回数を言う | 回数に進まない（3/3）→ 読み込み直す |
