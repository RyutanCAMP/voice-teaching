# ボイスティーチング（Voice Teaching）

**専門家が決めた枠の中で、現場の人がロボットに声で直しを頼める。**

既存の安川ロボット（今回の実証：HC20＋YRC1000）のジョブを、普段の言葉で直すためのアプリです。
「置く位置を右に10ミリ」と話しかけると、Claudeがジョブを読んで対象を特定し、専門家が決めた範囲の中かどうかをプログラムが検査し、人が画面で確認・承認してから、新しいジョブとしてロボットへ送ります。

> **2026年11月2日のキックオフ以降に、新しく作り始めました。** 開発の経過はコミット履歴で確認できます。

## 起動
Python 3.10以降で、リポジトリのフォルダーを開いて実行します。画面表示だけなら追加のPythonライブラリは不要です。

```powershell
python -m voice_teaching.web
```

[操作画面を開く](http://127.0.0.1:8765)。まず「公開用ダミーで試す」で読込・位置選択・経路再生を確認できます。
入力はサーバーのメモリー内だけで扱い、ファイルやログに保存しません。タブごとに状態を分けています。サーバーの終了・再起動で入力は失われます。

Claudeを使う場合は `.env.example` を `.env` にコピーし、利用可能なAPIキーとモデルIDを設定してサーバーを再起動してください。`.env` は公開しません。
モデルIDは自動選択しません。設定済みの表示だけでは接続確認済みとは扱いません。

変更案には、基準ファイルと一致する**専門家が設定したプレビュー用の枠**も必要です。未設定の軸・向き・変更上限は推定しません。
詳しくは [プレビューの操作と制約](docs/PREVIEW_WORKFLOW.md) を参照してください。

## 外部ライブラリとデータ

- 3D表示：Three.js 0.187.0（MIT）をローカル同梱。CDNには接続しません。配布元は [npm公式パッケージ](https://www.npmjs.com/package/three/v/0.187.0)、ライセンスは `voice_teaching/static/vendor/LICENSE.three.txt`。OrbitControlsのimport先を同梱ファイルに変更し、空白を2か所整えています。
- 使用データは `samples/dummy/DEMO_PLACE.JBI` の架空の座標です。HC20のCADや関節モデルは含みません。参考資料のコード・映像は同梱していません。
- Claudeには認識文（今回は文字入力）・固定した位置番号・位置番号一覧だけをサーバーから送ります。JBI本文・座標は送りません。APIキーはサーバー内だけで扱います。
- マイクは接続しておらず音声は送信しません。音声認識方式と送信先を確認してから追加します。

## 大事な注意
- アプリは**ロボットを起動しません**。動かすのは人が、ロボット側のスタートボタンで行います。
- 画面の図は変更前後を見比べるためのもので、**干渉や安全を保証するものではありません**。実機では必ず低速で動作を確認してください。
- ロボット・ペンダント・ジョブの転送機能は、安川電機の既存製品です。このリポジトリで作っているのは、それらとつなぐアプリの部分です。
